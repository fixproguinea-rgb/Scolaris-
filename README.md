# Scolaris

La scolarité, sans impayés : suivi des frais de scolarité par élève et relance automatique des parents en retard (WhatsApp / SMS).

- Cahier des charges : `CAHIER_DES_CHARGES.md`
- Stack : Flask (Python), Supabase (PostgreSQL), Vercel.
- Lancer en local : `pip install -r requirements.txt && python app.py`
- Tests : `python -m pytest -q`
